# Tic Tac Toe - GUI (Python Tkinter)

## Description

This project is a simple **Tic Tac Toe game with a graphical user interface (GUI)** built using Python and the Tkinter library. Two players can play the game by taking turns placing **X** and **O** on a 3×3 grid. The program automatically checks for the winner and allows the game to be reset.

## Features

* Interactive 3×3 Tic Tac Toe board
* Two-player gameplay (X and O)
* Winner detection
* Color indication for each player
* Reset button to restart the game

## Technologies Used

* Python
* Tkinter (GUI library)

## How to Run the Project

1. Install Python on your system.
2. Save the Python file (e.g., `tic_tac_toe.py`).
3. Open terminal or command prompt.
4. Run the following command:

```
python tic_tac_toe.py
```
